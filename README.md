# Touch Wood E-Commerce 🛒

A full-stack, decoupled e-commerce web application featuring a dynamic catalog of 8,000+ mock products and a functional shopping cart. Built and deployed entirely on the cloud. 

## 🌐 Live Demo
* **Frontend (Vercel):** https://touch-wood-ecommerce.vercel.app/
* **Backend API (Render):** https://touch-wood-ecommerce.vercel.app/

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Python, Flask, Flask-CORS
* **Deployment:** Vercel (Static Frontend) & Render (Web Service Backend)
* **Version Control:** Git & GitHub

## ✨ Key Features
* **Decoupled Architecture:** Clean separation of concerns between the user interface and the API.
* **RESTful API Integration:** Frontend asynchronously fetches product data and posts checkout payloads to the cloud server via JSON.
* **Dynamic Cart Management:** Real-time state management for adding items, calculating totals, and selecting payment methods (UPI/COD).
* **Stateless Mock Data:** Backend dynamically generates a massive catalog on-the-fly using Python's `random` module.
* **Cross-Origin Resource Sharing (CORS):** Fully configured to securely accept requests across different domains.
